# Narayana Naturals brand assets

The owner supplied the original logo on 18 October 2026 and requested improved image quality. The original 442 × 422 JPEG is preserved as `narayana-naturals-logo-original.jpg`.

The enhanced artwork uses two-color contour tracing, light edge cleanup, and cubic vector curves. The leaf, grain and lettering follow the supplied artwork; the lettering is stored as outlines and does not depend on an installed font. These files are derived from the supplied JPEG rather than an original designer vector master.

| File | Intended use |
| --- | --- |
| `narayana-naturals-logo.svg` | Transparent, scalable version of the supplied stacked logo |
| `narayana-naturals-logo-hd.png` | 3000 × 2865 PNG on a clean cream background, keeping the original placement |
| `narayana-naturals-logo-transparent.png` | 3000 × 1896 PNG with a genuinely transparent background and trimmed padding |
| `narayana-naturals-horizontal.svg` | Header layout using the same emblem and outlined lettering |
| `narayana-naturals-horizontal.png` | 2400 × 439 transparent PNG of the header layout |
| `narayana-naturals-mark.svg` | Leaf and grain emblem for small icons |
| `brand-assets.json` | Asset dimensions, source reference, and representative colors |

Representative colors extracted from the source: green `#2F553B`, grain brown `#8B603A`, and cream `#FAF6ED`. Preserve the artwork's aspect ratio when placing it.

The website serves lightweight SVG copies from `apps/web/public/brand` and uses the supplied identity in the header, footer, owner navigation, welcome guide, and packaging concepts. Browser and Apple touch icons live in `apps/web/src/app`. These assets can also be used by the future Flutter app.
